🤖 RAG with Agents

About the Project

RAG with Agents is an AI-powered question-answering application that combines Retrieval Augmented Generation with multiple AI agents.

The system retrieves relevant information from documents and uses AI agents to generate and review answers.

Features

- Document text input
- Document chunking
- Semantic search
- Context retrieval
- Research Agent
- Review Agent
- AI-powered question answering

Technologies Used

- Python
- Streamlit
- OpenRouter API
- OpenAI SDK
- Sentence Transformers
- Scikit-learn
- NumPy

Project Structure

RAG-with-Agents/
├── app.py
├── requirements.txt
└── README.md

Installation

pip install -r requirements.txt

Run Application

streamlit run app.py

Objective

To demonstrate how Retrieval Augmented Generation and multiple AI agents can work together to provide context-based answers.
